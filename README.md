## Deploy (GitHub Pages)
1. Push this folder to a GitHub repository
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save
3. Site goes live at `https://<username>.github.io/<repo>/` in ~2 minutes
